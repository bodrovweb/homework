# ai-production

Репозиторий является корнем кросс-инструментального плагина и описывает производственный процесс создания учебного контента: от продуктовой рамки и программы курса до урока, ревью, постпродакшена и проверки после заливки на платформу.

Поставляемое содержимое плагина живёт в корневых `skills/`, `agents/`, `commands/` и `context/`. `.agents/` используется только для локальных инструкций сопровождения и каталога плагинов Codex, `.cursor/` — как проекция для Cursor через симлинки.

## Установка в другой репозиторий

Этот репозиторий сам является корнем устанавливаемого плагина. В целевом проекте его удобнее подключать отдельным каталогом `.agents/plugins/ai-production`, чтобы версия плагина была явно зафиксирована в Git рядом с агентскими настройками проекта.
